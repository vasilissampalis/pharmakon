# Nitrous oxide — evidence map and PDF list (v0.1, 2026-10-15)

All DOIs below come from Crossref API responses retrieved on 2026-10-15 (never from memory). Each row's DOI, title, container-title, year and first author were returned by Crossref for that record. Retraction check: none of the retained records is retracted; three carry a published correction or corrigendum (items 24, 28, 75) and are marked. Save each PDF into `PDFs/Nitrous-oxide/` with the filename given; cross-cutting papers go in `PDFs/_Cross-cutting/`.

How this list was built: (1) 20 section-level and targeted Crossref bibliographic queries covering the monograph sections of METHODS §8 plus the substance-specific topics (B12 inactivation and myeloneuropathy, hyperhomocysteinemia, frostbite and pressure injury, deaths, cognition and psychiatry, medical and dental pharmacology, driving); (2) the landmark studies with their published critiques, replies and follow-ups (Layzer 1978/1979 with Adornato's correspondence; Back 2023 with Winstock's commentary and Brunt's review; Myles 2007 with the ENIGMA-II follow-ups); (3) a topic-level Crossref `has-update:true` screen to catch retractions and errata. All query strings are in `Nitrous-oxide_search-log.md`. The PubMed layer (strings in the search log) is still to be run and will add to this list; its results decide what is added or dropped, not this list.

Context note for the senior author: Crossref returned HTTP 429 on roughly one call in three in this window (shared egress), so pacing was 90–240 s between calls and the search was closed at 20 completed queries rather than the planned 24. The sections affected are named under "Known gaps".
