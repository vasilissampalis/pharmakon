# Cocaine — evidence map and PDF list (v0.1, 2026-10-15)

All DOIs below were taken verbatim from Crossref REST API responses on 2026-10-15 (search endpoint, `type:journal-article`), so every entry resolves to the Crossref record whose title is echoed in the table. Retraction/erratum check: none of the included papers is retracted; one carries a published corrigendum (Sabe et al. 2021), marked in the table. Save each PDF into `PDFs/Cocaine/` with the filename given. Cross-cutting papers go in `PDFs/_Cross-cutting/`.

How this list was built: (1) section-level Crossref bibliographic searches covering the monograph sections of METHODS §8; (2) targeted title/author searches for the landmark studies of each contested question and for their published critiques, replies and follow-ups; (3) screening by title and journal (conference abstracts, `Reactions Weekly` entries, single case reports and predatory-looking venues were dropped). The PubMed layer (strings in `Cocaine_search-log.md`) is still to be run and will add to this list; its results decide what is added or dropped, not this list.
