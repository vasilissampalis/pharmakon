# Benzodiazepines — evidence map and PDF list (v0.1, 2026-10-15)

All DOIs below were returned verbatim by Crossref in this session (Crossref `works?query.bibliographic=` records, which carry the same metadata and the same `update`/`updated-by` fields as the `works/<DOI>` endpoint). No DOI in this list was written from memory. Save each PDF into `PDFs/Benzodiazepines/` with the filename given; cross-cutting papers go in `PDFs/_Cross-cutting/`.

How this list was built: (1) 14 pre-specified section queries covering the monograph sections of METHODS §8 plus the substance-specific topics (dependence and withdrawal; opioid co-use and overdose mortality; the cognition/dementia debate *with* its published critiques; designer benzodiazepines; falls and fractures; z-drugs; prescribing trends; the flumazenil controversy); (2) landmark studies and the published critiques, replies and corrections attached to them, located by exact-title Crossref queries; (3) screening by title and journal — conference abstracts, `Reactions Weekly`/`Inpharma Weekly` news items, predatory-looking venues and off-topic hits were dropped.

Crossref throttled this session very heavily (HTTP 429 after roughly every second request for the whole session, with pauses of 90–240 s between requests as the brief requires; direct non-WebFetch access to the API is blocked in this environment). The discovery layer is therefore thinner than it should be: 14 of ~20 planned queries were run, and a substantial set of landmark papers that could not be reached before the queries ran out is listed by title under "Known gaps". The PubMed layer (strings in `Benzodiazepines_search-log.md`) is still to be run and will add to this list; its results decide what is added or dropped, not this list.

**Work through the list in order. Tier A first. Tell me each time you finish a batch of ten and I will start reading.**
