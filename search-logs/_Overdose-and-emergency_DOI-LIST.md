# _Overdose-and-emergency — evidence map and PDF list (v0.1, 2026-10-15)

Cross-cutting topic: recognition of, and first response to, acute drug toxicity by drug class — opioid overdose and naloxone administration; stimulant toxicity and "overamping"; serotonin toxicity; hyperthermia; GHB coma; alcohol poisoning; benzodiazepine overdose and the flumazenil question; the recovery position; bystander CPR in overdose; emergency-department toxicology surveillance; and remote ("never use alone") overdose-response services. This is the evidence base the site's emergency page draws on. Save each PDF into `PDFs/_Cross-cutting/` with the filename given.

How this list was built: (1) Crossref bibliographic searches on the pre-registered section queries (`_Overdose-and-emergency_search-log.md`); (2) landmark studies retrieved together with their published critiques, replies and corrections, as METHODS §2.3(3) requires — the flumazenil, GHB-physostigmine, GHB-agitation, NACARDI and recovery-position clusters below each carry their own critique; (3) screening by title and journal (dropped: news digests, *Reactions Weekly*/*Inpharma* items, conference abstracts, trial registrations, predatory-looking venues, and off-topic hits). The PubMed layer (strings in the log) is still to be run and will add to this list.

**Verification.** Every DOI below was returned verbatim by a Crossref `works?query.bibliographic=` search in this session, together with the title, container-title, year and first author echoed in the table — i.e. each DOI is registered with Crossref and resolves to the paper named (the brief's verification standard for search-derived DOIs). No DOI in this list was written from memory. Items whose Crossref record carries a published correction are marked **erratum published** and the correction's own DOI is given; the correction must be obtained with the paper. Where Crossref lists no author, the table says so.

**Language note (METHODS §9).** Titles are reproduced exactly as Crossref returns them, including the word "abuse" where it appears in a title; the editors' own text does not use it.

## Known gaps this list does not yet cover

The Crossref search endpoint was shared with other co-editor sessions and returned HTTP 429 on roughly half of all calls; eleven of the fourteen pre-registered queries were run (see the log). The following are known to exist and are **not** in the list above because no DOI for them was obtained by Crossref search in this session. None should be entered into the reference library until its DOI has been verified.

- **Euro-DEN Plus core papers.** The network-description paper (Wood, Heyerdahl, Yates, Dines, Giraudon, Hovda & Dargan, *Clinical Toxicology* 2014, "The European Drug Emergencies Network (Euro-DEN)") and the first 12-month data paper (Dines et al., *Clinical Toxicology* 2015) were not returned by the surveillance query; the surveillance items retained (29, 30, 60–64) are from the same group but are not the cohort papers themselves. High priority for the PubMed layer.
